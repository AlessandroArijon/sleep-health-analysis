# Sleep Health Analysis

Academic Business Analytics project exploring factors associated with sleep disorders.

The analysis uses Python to clean and explore a sleep health dataset, visualize relationships between variables, and compare decision tree classification models.

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Imbalanced-learn.

## Files

- `sleep_health_analysis.ipynb`: data exploration, preprocessing, visualizations and machine learning experiments.
- `sleep_health.csv`: dataset used in the analysis.

## Note

This is an academic exploratory project. Its predictive results are educational and should not be used for medical diagnosis.
